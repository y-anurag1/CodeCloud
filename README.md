# CodeCloud

CodeCloud is a clone of LeetCode, a platform for developers to practice coding problems and improve their skills. This project was created as a full-stack project _(my first full-stack project)_ using Express, MongoDB, Mongoose, TypeScript,TypeScript React (TSX), CSS3, and Tailwind CSS.

# Demo

[https://codecloudupes.vercel.app/](https://codecloudupes.vercel.app/)

# Installation

### Clone the repository and install server and client dependencies:

```bash
git clone https://github.com/ManiGhazaee/CodeCloud.git
cd CodeCloud/server
npm install
cd ../client
npm install
```
